「Web Page Scroller」は、ウェブページを開いてスペースバーを押したときのスクロール量を変更するChromeの拡張機能です。  
  
【ウェブページのスクロール】  
Chromeなどのウェブブラウザでウェブページを表示しているときにスペースバーを押すと、ウェブページが下側へスクロールされ、Shift+スペースバーを押すと、ウェブページが上側へスクロールされます。このときのスクロール量は表示画面の１ページ分であり、Chromeなどのウェブブラウザには、このスクロール量を変更するための設定がありません。  
  
【スペースバーを押したときのスクロールの問題点】  
「x.com」などのように、タブバーが表示されているウェブページをスクロールすると、タブバーの下層のウェブページの内容が見えないため、見かけ上、ウェブページが、１ページ分以上スクロールされたように見えます。  
ウェブページの見えない部分を見るためには、ウェブページをスクロールした後、少しだけスクロールバックする必要があり、面倒です。  
  
【「Web Page Scroller」の特徴】  
「Web Page Scroller」は、スペースバーを押したときのウェブページのスクロール量を１％単位で変更したり、ウェブページを１フレーム当たり１ピクセル単位で自動スクロールしたりできます。  
  
【「Web Page Scroller」のインストール】  
(1) Chromeの拡張機能の「デベロッパーモード」をONに設定します。  
(2) 「パッケージ化されていない拡張機能を読み込む」をクリックします。  
(3) この拡張機能が保存されているフォルダを選択します。  
  
【「Web Page Scroller」の設定】  
(1) 「グローバルスクロール量」は、スペースバーを押したときのウェブページのスクロール量を設定します。デフォルトのグローバルスクロール量は、100%です。  
(2) 「サイト別スクロール量」は、タブバーの高さに応じて、タブバーが表示されているウェブページのスクロール量を、例えば、90%に設定します。あるいは、ウェブページを表示しているときに、この拡張機能のアイコンをクリックすると、ウェブページのスクロール量を登録するダイアログが開きます。  
(3) 「自動スクロール」は、ウェブページを自動スクロールするときの１フレーム当たりの速度（ピクセル）を設定します。デフォルトの自動スクロール量は、１フレーム当たり１ピクセルです。  
(4) 「疑似ブックマーク保存」は、「Web Page Scroller」の設定を疑似ブックマークとして保存するフォルダを設定します。  
  
【「Web Page Scroller」の使い方】  
(1) ウェブページを表示します。  
(2) スペースバーを押すと、オプションで設定したスクロール量で、ウェブページが下側へスクロールされ、Shift+スペースバーを押すと、オプションで設定したスクロール量で、ウェブページが上側へスクロールされます。  
(3) 「Ctrl+Shift+Z」を押すと、オプションで設定した自動スクロール速度で、ウェブページが下側へ自動スクロールし、もう一度、「Ctrl+Shift+Z」を押すか、ESCを押すと、自動スクロールが停止します。  
  
【まとめ】  
「Web Page Scroller」を使えば、スペースバーを押したときのウェブページのスクロール量を自由に変更してウェブページを表示したり、ウェブページを自動スクロールして表示したりすることができます。
